Production

This project had its own producer; therefore, we were able to effectively keep development to weekly sprints that we tracked with a Trello Board. Task priority was designated by a MoSCoW diagram which allowed us to easily cut content when certain deadlines grew close.

Design

For this project we were tasked to create a traditional 3v3 turn-based strategy game, so a lot of research was conducted to try and capture the feel of older games within the genre.

A focus of this project was on the UX heuristic of Error Prevention; which was incorporated into the design with the use of Confirmation Boxes, Tool Tips and clear Call To Action Elements

Reflection

As a personal note, I would say I performed well on this assignment and was able to create a fully functional note. However, there were several issues that I faced during development.

Unfortunately, due to certain delays mock ups couldn’t be completed which meant that Engine Implementation had to be done using the wireframes. Additionally; due to the tight deadlines it meant that there wasn’t much time to revise previous designs before moving on to the next sprint, which caused for some designs to be fixed in Engine if any issues arose.
